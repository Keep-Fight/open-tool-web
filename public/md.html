Getting Started with Open Toolbox

Learn how to configure your digital workspace using the Open Toolbox architectural primitives. This guide covers the initial setup, dependency management, and your first tool deployment.

terminal

Prerequisites

Ensure you have Node.js v18+ and a Git-compatible shell environment installed before proceeding.

Installation

To begin, install the CLI globally using your preferred package manager. We recommend pnpm for faster resolution and reduced disk usage.

$ pnpm install -g @open-toolbox/cli
$ otbx init my-project
$ cd my-project && otbx start

Configuration Parameters

The otbx.config.json file serves as the source of truth for your toolbox instance. Define your modules and hooks here.

Parameter Type Default Description
root_dir String ./tools Base directory for all custom tool binaries.
strict_mode Boolean true Enforces architectural validation on build.
port Number 8080 Local development server listener port.
Open Toolbox utilizes a "Lock-Step" deployment mechanism. This ensures that no individual component is updated without verification from the global registry.

Advanced Architecture

When scaling to enterprise environments, the architectural depth of the toolbox allows for isolated execution environments. This is particularly useful for teams managing heterogeneous stacks.

Layered Auth

Integrated OAuth2 and OpenID Connect protocols with zero-config setup.

Atomic State

Propagate updates across the toolkit with microsecond latency using shared buffers.
